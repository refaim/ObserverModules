Версия 2.1.2
------------
 * исправлен невыровненный доступ к упакованному выходному буферу Observer, заполняемому при выводе общей информации об архиве.
 * исправлен невыровненный доступ к упакованному выходному буферу Observer, заполняемому при перечислении файлов архива.

Версия 2.1.1
------------
 * извлечение из обрамлённых PAK больше не дописывает четырёхбайтовый хвост в конец файла.
 * размеры и прогресс извлечения для обрамлённых архивов теперь корректны.
 * для архивов, не соответствующих формату с обрамлением, сохранено прежнее поведение извлечения.
 * исправлен невыровненный доступ к путям при открытии и извлечении архивов через Observer.

Версия 2.1.0
------------
 + добавлены самодостаточные сборки, не требующие установки дополнительного окружения.
 * повреждённые и усечённые архивы теперь корректно отклоняются с ошибкой.
 * исправлены имена файлов: сохранённые относительные пути больше не теряют первые символы.

Версия 2.0.0
------------
 + добавлена поддержка оригинального варианта PAK и варианта для Steam.
 + добавлены сборки x86.
 * исправлена работа модуля: архивы открываются, а их содержимое отображается правильно.
 * исправлено извлечение обрезанных файлов, которые теряли последние байты.

Версия 1.0.0
------------
 + добавлен первый рабочий модуль PAK: он показывает и извлекает архивы игры Zanzarah: The Hidden Portal.
