Version 2.2.0
-------------
 * Build Release modules with MSVC v145, the static /MT Spectre CRT and source-built hardened YY-Thunks XP objects, without VC-LTL or extra runtime DLLs.
 * Ship one binary per architecture, with PE minimum 5.01 (x86) or 5.02 (x64), retaining /GS, /Qspectre and the Observer ABI.

Version 2.1.2
-------------
 * Fixed misaligned access to the packed Observer output buffer written when reporting general archive information.
 * Fixed misaligned access to the packed Observer output buffer written when listing archive entries.

Version 2.1.1
-------------
 * Framed PAK extraction no longer appends a four-byte footer to the extracted file.
 * Sizes and extraction progress for framed archives are now correct.
 * Archives that do not match the framed layout retain the previous extraction behavior.
 * Fixed unaligned path access when opening and extracting archives through Observer.

Version 2.1.0
-------------
 + Added self-contained builds that need no extra runtime installation.
 * Malformed and truncated archives are now rejected with an error.
 * Fixed file names so stored relative paths are preserved instead of losing their first characters.

Version 2.0.0
-------------
 + Added support for both the original and the Steam PAK variants.
 + Added x86 builds.
 * Fixed the module so that archives open and their contents list correctly.
 * Fixed extracted files that were cut short and lost their last bytes.

Version 1.0.0
-------------
 + Added the first working PAK module: it lists and extracts archives from Zanzarah: The Hidden Portal.
