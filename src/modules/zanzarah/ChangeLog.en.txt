Version 2.1.0
-------------
 + Added ARM64 builds alongside the existing x86 and x64 builds.
 + Added self-contained builds that need no extra runtime installation.
 * Malformed and truncated archives are now rejected with an error.
 * Fixed file names so stored relative paths are preserved instead of losing their first characters.

Version 2.0.0
-------------
 + Added support for both the original and the Steam PAK variants.
 + Added x86 builds.
 * Fixed the module so that archives open and their contents list correctly.
 * Fixed extracted files that were cut short and lost their last bytes.

Version 1.0.0
-------------
 + Added the first working PAK module: it lists and extracts archives from Zanzarah: The Hidden Portal.
