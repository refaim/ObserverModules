Версия 1.3.0
-------------
 * Release-модули собираются MSVC v145 со статическим /MT Spectre CRT и защищёнными XP-объектами YY-Thunks из исходников, без VC-LTL и дополнительных runtime DLL.
 * Для каждой архитектуры выпускается один файл с минимумом PE 5.01 (x86) или 5.02 (x64); сохранены /GS, /Qspectre и ABI Observer.

Версия 1.2.0
------------
 * исправлен невыровненный доступ к упакованным выходным буферам Observer, которые заполняются при выводе информации об архиве.
 + добавлена нативная поддержка архивов RPG Maker XP (.rgssad) и VX (.rgss2a) наряду с VX Ace: модуль показывает и извлекает файлы из всех трёх форматов и поколений.
 * повреждённые и усечённые архивы версии 1 теперь отклоняются с ошибкой.

Версия 1.1.1
------------
 * исправлен невыровненный доступ к путям при открытии архивов через Observer.
 * исправлен невыровненный доступ к пути назначения при извлечении архивов через Observer.

Версия 1.1.0
------------
 + добавлены самодостаточные сборки, не требующие установки дополнительного окружения.
 * повреждённые и усечённые архивы теперь корректно отклоняются с ошибкой.

Версия 1.0.0
------------
 + добавлен первый рабочий модуль RPG Maker VX Ace: он показывает и извлекает файлы из архивов RGSS3A (.rgss3a).
 + добавлено полное извлечение каждой записи, включая последние байты файла.
