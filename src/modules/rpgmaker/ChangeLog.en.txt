Version 1.3.0
-------------
 * Build Release modules with MSVC v145, the static /MT Spectre CRT and source-built hardened YY-Thunks XP objects, without VC-LTL or extra runtime DLLs.
 * Ship one binary per architecture, with PE minimum 5.01 (x86) or 5.02 (x64), retaining /GS, /Qspectre and the Observer ABI.

Version 1.2.0
-------------
 * Fixed misaligned access to the packed Observer output buffers that are filled while listing archive information.
 + Added native RPG Maker XP (.rgssad) and VX (.rgss2a) archive support alongside VX Ace: the module now lists and extracts all three formats and generations.
 * Malformed or truncated version 1 archives are now rejected with an error.

Version 1.1.1
-------------
 * Fixed unaligned path access when opening archives through Observer.
 * Fixed unaligned destination path access when extracting archives through Observer.

Version 1.1.0
-------------
 + Added self-contained builds that need no extra runtime installation.
 * Malformed and truncated archives are now rejected with an error.

Version 1.0.0
-------------
 + Added the first working RPG Maker VX Ace module: it lists and extracts files from RGSS3A (.rgss3a) archives.
 + Added complete extraction of every entry, including the final bytes of a file.
