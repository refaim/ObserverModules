Version 3.1.3
-------------
 * Reject indexes with more than 64 nested Pickle containers.
 * Preserve the nesting limit across memo copies and container updates so value copying and cleanup stay bounded.

Version 3.1.2
-------------
 * Fixed misaligned access to the packed Observer output buffer written when reporting general archive information.
 * Fixed misaligned access to the packed Observer output buffer written when listing archive entries.

Version 3.1.1
-------------
 * Fixed unaligned path access when opening archives through Observer.
 * Fixed unaligned destination path access when extracting archives through Observer.

Version 3.1.0
-------------
 + Added self-contained builds that need no extra runtime installation.
 * Fixed opening archives with a corrupted or malformed index.

Version 3.0.0
-------------
 + Added support for RPA 2.0 archives.
 + Improved compatibility with RPA 3.0 archives.
 + Added x86 builds and removed the external Python requirement, so the module works on machines without Python.
 + Improved the speed of opening archives with many files.
 * Fixed extraction of prefixed entries, which no longer gain extra garbage at the end of the file.

Version 2.0.0
-------------
 + Improved compatibility with archives from older Ren'Py games created with Python 2.
 * Fixed progress reporting during extraction.
 * Fixed opening archives larger than 4 GiB.
 * Fixed a crash when opening certain archives.

Version 1.0.0
-------------
 + Added the first working Ren'Py module: it lists and extracts files from RPA 3.0 archives, including file names that use non-ASCII characters.
