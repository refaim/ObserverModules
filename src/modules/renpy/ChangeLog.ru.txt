Версия 3.1.0
------------
 + добавлены сборки для ARM64 вместе с уже существующими сборками x86 и x64.
 + добавлены самодостаточные сборки, не требующие установки дополнительного окружения.
 * исправлено открытие архивов с повреждённым или некорректным индексом.

Версия 3.0.0
------------
 + добавлена поддержка архивов RPA 2.0.
 + расширена совместимость с архивами RPA 3.0.
 + добавлены сборки x86 и убрана зависимость от внешнего Python: модуль работает даже без установленного Python.
 + ускорено открытие архивов с большим числом файлов.
 * исправлено извлечение записей с префиксом: в конец файла больше не добавляется мусор.

Версия 2.0.0
------------
 + расширена совместимость с архивами старых игр Ren'Py, созданными с помощью Python 2.
 * исправлен показ прогресса при извлечении.
 * исправлено открытие архивов размером больше 4 ГиБ.
 * исправлено падение при открытии некоторых архивов.

Версия 1.0.0
------------
 + добавлен первый рабочий модуль Ren'Py: он показывает и извлекает файлы из архивов RPA 3.0, включая имена файлов с символами, отличными от ASCII.
